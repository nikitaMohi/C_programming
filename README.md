# C Programming Concepts

A structured collection of C programs created while learning the C programming language, from core fundamentals to pointers, memory management, and file handling. Each topic is supported by hands-on code examples, making this repository both a learning record and a quick revision reference.

---

## About This Repository

This repository documents my C learning journey. Programs are added regularly as each new concept is learned and practiced. It contains:

- Clean, well-commented example programs for each topic
- A progressive structure, moving from basic to advanced concepts
- Practice problems that reinforce each concept
- Continuous updates as new topics are completed

## Objectives

- Build a strong foundation in C programming and programming logic
- Understand how memory, pointers, and data structures work at a low level
- Understand how every C program executes internally and how the operating system allocates and manages memory
- Strengthen problem-solving skills through consistent practice
- Maintain an organized reference for future revision

---

## Topics Covered

### 1. C Basics
- Introduction to C and the program compilation process
- Structure of a C program
- Variables, constants, and data types
- Operators and type conversion
- Input and output using `printf` and `scanf`

### 2. Control Flow
- `if`, `if-else`, `else-if` ladder, and nested `if`
- `switch` statement
- Loops: `for`, `while`, `do-while`
- `break`, `continue`, and `goto`
- Pattern printing programs

### 3. Functions
- Function declaration, definition, and calling
- Parameters and return types
- Call by value and call by reference
- Recursion
- Storage classes: `auto`, `static`, `extern`, `register`

### 4. Arrays
- One-dimensional and multi-dimensional arrays
- Array operations: searching, sorting, and traversal
- Passing arrays to functions

### 5. Strings
- Character arrays and string handling
- String library functions from `string.h`
- String manipulation programs

### 6. Pointers
- Pointer declaration and dereferencing
- Pointer arithmetic
- Pointers and arrays
- Pointers and functions
- Pointer to pointer
- Function pointers

### 7. Dynamic Memory Allocation
- `malloc`, `calloc`, `realloc`, and `free`
- Memory leaks and dangling pointers
- Stack and heap memory

### 8. Structures and Unions
- Structures and nested structures
- Array of structures
- Pointers to structures
- Unions
- Enumerations
- `typedef`

### 9. File Handling
- Opening, reading, writing, and closing files
- Text and binary files
- File pointers and positioning functions

### 10. Preprocessor and Additional Concepts
- Macros and `#define`
- Header files and conditional compilation
- Bitwise operators
- Command-line arguments

### 11. Data Structures in C
- Linked lists
- Stacks and queues
- Searching and sorting algorithms

### 12. Program Internals and Memory Management
- Compilation stages in detail: preprocessing, compilation, assembly, and linking
- Program memory layout: text, data, BSS, heap, and stack segments
- How variables are stored: local, global, static, and dynamically allocated memory
- Stack frames, function call mechanism, and return addresses
- How the operating system loads and executes a program
- Process address space and virtual memory
- Paging, page tables, and the role of the memory management unit
- How `malloc` and `free` obtain and manage memory from the heap
- System calls and the interaction between user space and kernel space
- Common memory errors: stack overflow, buffer overflow, segmentation faults, and undefined behavior

This list is updated as new topics are completed.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/nikitaMohi/<name>.git
   ```

2. Navigate to the project directory:
   ```bash
   cd <name>
   ```

3. Compile a C file:
   ```bash
   gcc filename.c -o filename
   ```

4. Run the program:
   ```bash
   ./filename
   ```

On Windows, run the executable with `filename.exe`. Ensure GCC is installed by running `gcc --version`.
